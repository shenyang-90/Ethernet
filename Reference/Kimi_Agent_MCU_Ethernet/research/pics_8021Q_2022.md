# IEEE Std 802.1Q-2022 协议分析与PICS提取报告

## 1. 协议概述分析

### 1.1 协议总体范围和结构

IEEE Std 802.1Q-2022是IEEE关于桥接网络和VLAN桥接的核心标准，全称为《IEEE Standard for Local and Metropolitan Area Networks: Bridges and Bridged Networks》。该标准于2022年9月21日由IEEE SA Standards Board批准，是2018版本的修订版，共2163页。

标准的核心目标是规定Media Access Control (MAC) Service在桥接网络中的支持方式，包括MAC Bridge和VLAN Bridge的操作原理、管理协议和算法。标准涵盖以下关键技术领域：

- **VLAN桥接基础**：包括C-VLAN Bridge、S-VLAN Bridge（Provider Bridge）、Backbone Edge Bridge等架构
- **生成树协议**：RSTP（Rapid Spanning Tree Protocol）和MSTP（Multiple Spanning Tree Protocol）
- **注册协议**：MMRP、MVRP、MRP等
- **连接性故障管理**：CFM（Connectivity Fault Management）
- **TSN（Time-Sensitive Networking）相关协议**：包括802.1Qav、802.1Qbv、802.1Qbu、802.1Qci、802.1Qca等
- **数据中心桥接**：PFC、ETS、DCBX等
- **最短路径桥接**：SPB Protocol

### 1.2 VLAN桥接基础功能

VLAN桥接基础功能包括：
- **帧中继与过滤**：基于MAC地址和VLAN ID的帧转发决策
- **VLAN标签处理**：插入、修改和移除C-TAG/S-TAG/I-TAG
- **优先级处理**：基于802.1p priority的 traffic classification
- **地址学习与管理**：动态MAC地址学习和静态配置
- **生成树协议支持**：RSTP/MSTP用于防止环路
- **远程管理**：SNMP MIB、YANG数据模型

### 1.3 TSN相关子协议概述

#### 1.3.1 802.1Qav — Credit-Based Shaper (CBS)

**基于信用的整形器**是TSN中最早被广泛采用的流量整形机制。CBS通过维护一个credit计数器来控制SR（Stream Reservation）类流量的传输。当端口上有SR流量等待传输时，credit以idleSlope速率增加；当SR流量正在传输时，credit以sendSlope速率减少。只有在credit为非负值时才允许传输SR帧。

CBS的关键参数包括：
- **idleSlope**：信用增加速率，反映为SR类预留的带宽比例
- **sendSlope**：信用减少速率，等于端口传输速率与idleSlope之差
- **hiCredit**：信用上限，防止突发
- **loCredit**：信用下限

CBS适用于需要确定性带宽预留但不严格要求极低延迟的场景，如音频视频传输（AVB）。

#### 1.3.2 802.1Qbv — Time-Aware Shaper (TAS)

**时间感知整形器**（又称门控调度）是实现确定性最低延迟的核心TSN机制。TAS通过Gate Control List (GCL)精确控制每个队列的开启和关闭时间。每个队列都有一个gate，gate状态可以是Open或Closed。GCL按照预定义的时间表循环执行，在每个时间间隔内只允许特定队列传输。

TAS的关键组成包括：
- **Gate Control List (GCL)**：定义gate状态和对应的时间间隔
- **Cycle Timer State Machine**：维护周期定时
- **List Execute State Machine**：顺序执行GCL中的操作
- **List Config State Machine**：管理GCL的动态更新

TAS通常与802.1AS (gPTP)时间同步配合使用，确保所有桥接设备的调度表精确同步。TAS适用于硬实时控制流量，如汽车中的线控制动（brake-by-wire）。

#### 1.3.3 802.1Qbu/802.3br — Frame Preemption

**帧抢占**允许高优先级的时间关键帧中断低优先级帧的传输。当一个Express帧到达而端口正在传输一个可抢占帧时，可抢占帧可以被暂停（preempted），Express帧优先传输完成后，被抢占的帧从断点处继续传输。

帧抢占的关键特性：
- **Express帧**：不可抢占的高优先级帧（通常为时间关键控制流量）
- **可抢占帧**：可被中断的低优先级帧
- **帧校验序列(FCS)**：被抢占的帧使用特殊的mCRC标记
- **802.3br MAC Merge子层**：处理抢占的底层机制

帧抢占与TAS结合使用可以实现更精确的时间窗口控制。

#### 1.3.4 802.1Qci — Per-Stream Filtering and Policing (PSFP)

**逐流过滤和策略**提供了基于流的精细流量控制机制。PSFP对每个流（Stream）进行独立的过滤、计量和门控操作。

PSFP的核心组件包括：
- **Stream Filter**：基于匹配规则识别特定流
- **Stream Gate**：控制流是否被允许通过（Open/Closed状态）
- **Flow Meter**：SRP（Single Rate Three Color Marker）三色标记算法进行流量计量
- **Stream Gate Control List**：类似于TAS的GCL，对流门控进行时间调度

PSFP对安全关键应用至关重要，可以防止错误ECU或恶意节点向网络注入过多流量，保护关键控制流量。

#### 1.3.5 802.1Qca — Path Control and Reservation

**路径控制和预留**基于IS-IS协议扩展，支持显式的流量工程路径控制。通过定义ECT（Equal Cost Tree）算法和网络资源预留，Qca允许为特定流量流预留端到端路径和带宽资源。

### 1.4 TSN协议对区域控制器（Zonal Controller）含Switch的应用意义

在汽车zonal架构中，区域控制器通常集成Ethernet Switch功能，TSN协议具有以下关键意义：

1. **确定性通信保障**：TAS+Qbu确保控制类流量（如底盘控制）在严格时间窗口内到达
2. **带宽隔离与预留**：CBS为不同流量类型（信息娱乐、ADAS、控制）分配隔离带宽
3. **安全与防护**：PSFP防止流量风暴和错误注入，满足ASIL等级要求
4. **灵活性和可扩展性**：基于802.1Q的VLAN和优先级机制支持功能扩展
5. **多OEM兼容性**：IEEE标准化确保不同供应商设备互操作

对于区域控制器芯片（如Infineon TC4x、NXP S32G、Renesas R-Car S4），TSN硬件加速支持是选型的关键考量：
- **TC4x**：集成TSN-capable Ethernet Switch，硬件支持TAS/CBS
- **S32G**：PFE（Packet Forwarding Engine）支持TSN协议卸载
- **R-Car S4**：集成Switch支持TSN功能

## 5. 总结与建议

### 5.1 关键发现

1. **PICS完整性**：IEEE 802.1Q-2022在Annex A（Bridge）和Annex B（End Station）中提供了完整的PICS proforma，涵盖所有TSN子协议。

2. **TSN功能均为Optional**：在PICS major capabilities中，FQTSS、SCHED、PRE、PSFP、ATS、CQF、PCR均被标记为**O（Optional）**，这意味着标准本身不强制要求实现任何TSN功能。但在实际的汽车区域控制器应用中，这些功能通常被提升为**Must**要求。

3. **Mandatory依赖条件**：当声明支持某个TSN功能时，其详细PICS条目变为Mandatory（M）。例如：
   - 声明支持SCHED后，SCHED1和SCHED2变为M
   - 声明支持PRE后，PRE1变为M
   - 声明支持PSFP后，PSFP1和PSFP2变为M

4. **CQF依赖关系**：CQF功能同时依赖SCHED和PSFP，体现了循环排队转发与门控调度的紧密耦合。

### 5.2 区域控制器TSN实施建议

1. **基础功能必须支持**：VLAN Bridge、RSTP、多traffic classes、VLAN tagging
2. **核心TSN功能硬件实现**：TAS、CBS、Frame Preemption、PSFP应通过硬件Switch IP实现
3. **软件协议栈**：SRP/MSRP、YANG/NETCONF管理、IS-IS PCR可通过MCU软件实现
4. **PSFP安全配置**：在汽车安全关键场景中，PSFP必须配置流过滤和策略以防止流量风暴
5. **时钟同步配合**：TAS功能必须配合802.1AS (gPTP)时间同步使用
