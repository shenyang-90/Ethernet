# IEEE Std 802.3-2022 协议分析与PICS提取报告

## 车载以太网（Automotive Ethernet）相关部分

---

## 1. 协议概述分析

### 1.1 IEEE Std 802.3-2022 总体范围

IEEE Std 802.3-2022是IEEE发布的最新版Ethernet标准，全文超过7000页，涵盖了从10Mbps到400Gbps的各种物理层规范。该标准定义了以太网的MAC（Media Access Control）子层和多种物理层（PHY）实现，包括线缆类型、接口规范、电气特性、协议一致性等内容。在车载网络领域，标准中定义的**单对双绞线车载以太网**（Single-Pair Automotive Ethernet）已成为现代汽车电子架构（EEA）的核心通信技术。

### 1.2 车载相关物理层规范

标准中定义了以下车载专用物理层规范，这些规范均为**单对双绞线**（single balanced pair）实现，大幅减少了布线重量和成本：

**100BASE-T1（Clause 96）**：源自IEEE 802.3bw-2015，支持100Mbps全双工通信，采用PAM3调制和3B/4B编码方案。100BASE-T1是当前车载网络中**最广泛部署**的物理层，主要用于车身控制、传感器接口、信息娱乐等领域。其链路传输距离可达15米，满足大多数车内通信需求。TC4x、S32G、S32K3等主流车载MCU均支持此速率。

**1000BASE-T1（Clause 97）**：源自IEEE 802.3bp-2016，支持1Gbps全双工通信，采用PAM3调制和80B/81B编码配合RS-FEC（450,406）前向纠错。1000BASE-T1主要用于ADAS域控制器、IVI系统、高速传感器聚合等对带宽要求较高的场景。TC4x和S32G系列MCU支持1G速率。

**10BASE-T1S（Clause 147-148）**：源自IEEE 802.3cg-2019，支持10Mbps半双工通信，采用差分曼彻斯特编码（DME）。其特色在于支持**多点总线拓扑**（multidrop）和**PLCA**（Physical Layer Collision Avoidance，物理层冲突避免）机制，可在同一总线上连接多达8个节点。10BASE-T1S适用于低成本的传感器/执行器网络，是CAN/LIN网络的潜在替代方案。

**2.5GBASE-T1 / 5GBASE-T1 / 10GBASE-T1（Clause 149-150）**：源自IEEE 802.3ch-2020，支持多Gbps速率的全双工通信，采用PAM4调制和64B/65B编码。这些高速物理层主要用于下一代ADAS/AD域控制器、高分辨率摄像头聚合、骨干网络等场景，支持15米传输距离（10GBASE-T1可达10米）。TC4x支持2.5G/5G速率。

### 1.3 MAC层规范

IEEE 802.3-2022定义了统一的MAC层帧格式（Clause 3），包括目的地址（DA）、源地址（SA）、Length/Type字段、MAC Client Data和FCS校验。所有车载PHY均使用相同的MAC帧格式。关键MAC层特性包括：

- **全双工/半双工操作**：100BASE-T1、1000BASE-T1和多Gig T1仅支持全双工模式；10BASE-T1S支持半双工模式
- **VLAN Tagging**：支持IEEE 802.1Q VLAN标签（Q-tagged frame），最大帧长可扩展至1522 octets
- **流量控制**：支持802.3x PAUSE帧（Annex 31B）和802.1Qbb PFC（Priority-based Flow Control, Annex 31D），后者支持按优先级独立暂停
- **巨型帧（Jumbo Frame）**：虽然不是标准强制要求，但大多数实现支持超过1518字节的帧
- **EEE**（Energy-Efficient Ethernet）：部分车载PHY支持低功耗空闲（LPI）模式

### 1.4 物理层接口

车载MCU与PHY之间通过标准MII接口通信：

| 接口 | 数据宽度 | 速率 | 适用PHY | 车载MCU支持 |
|------|---------|------|---------|-------------|
| MII | 4-bit | 25MHz | 100BASE-T1 | S32K3, S32G |
| RMII | 2-bit | 50MHz | 100BASE-T1 | 部分MCU |
| RGMII | 4-bit DDR | 125MHz | 1000BASE-T1 | TC4x, S32G |
| SGMII | Serial | 1.25Gbps | 1000BASE-T1 | S32G |
| USXGMII | Serial | 10Gbps | 多Gig T1 | TC4x |

### 1.5 车载网络应用场景

| 速率 | 应用场景 | 域控制器 | 拓扑 |
|------|---------|---------|------|
| 10Mbps (10BASE-T1S) | 传感器/执行器、车门、座椅 | 无 | 多点总线 |
| 100Mbps (100BASE-T1) | 车身控制、信息娱乐、常规传感器 | S32K3 | 点对点 |
| 1Gbps (1000BASE-T1) | ADAS、IVI、网关 | S32G, TC4x | 点对点 |
| 2.5/5Gbps | ADAS域控、摄像头聚合 | TC4x | 点对点 |
| 10Gbps (10GBASE-T1) | 骨干网、中央计算 | 高端SoC | 点对点 |

## 8. 总结与建议

### 8.1 车载Zonal Controller PHY选型指导

| 应用场景 | 推荐PHY | 推荐MCU | 关键考量 |
|---------|---------|---------|---------|
| 车身域 (Door/Seat/Light) | 100BASE-T1 | S32K3 | 成本、功耗 |
| 网关 (Central Gateway) | 1000BASE-T1 x N | S32G | 端口数、吞吐量 |
| ADAS域控 | 1000BASE-T1 / 2.5GBASE-T1 | TC4x, S32G | 带宽、延迟 |
| IVI系统 | 1000BASE-T1 | TC4x, S32G | 带宽、AVB/TSN |
| 传感器/执行器总线 | 10BASE-T1S (+PLCA) | S32K3 | 成本、拓扑灵活性 |
| 骨干网络 | 2.5G/5G/10GBASE-T1 | TC4x | 最高带宽 |

### 8.2 PICS使用建议

1. **供应商PICS填写**：要求PHY供应商提供完整的PICS proforma，特别是Auto-Negotiation、EEE、OAM等可选功能的实际支持情况
2. **MCU MAC PICS验证**：验证MCU的GMAC是否支持所需的TSN特性（如PFC、802.1Qbv门控等）
3. **系统集成PICS**：在zonal controller系统级别，需要整合PHY PICS和MAC PICS，确保端到端功能一致性
4. **EMC相关PICS**：所有车载PHY必须通过ISO 16750系列和CISPR 25 EMC测试
5. **延迟约束验证**：对于TSN应用，必须验证PHY+MAC的总延迟满足802.1AS gPTP的要求
