
This release includes documentation, core-driver source code for the provided
Cadence IP.

Core driver source is available in the core_driver/ directory.
  core_driver/include - public C headers, for inclusion in your code
  core_driver/src - ASF Core Driver's source code and headers

Please see the documentation in the doc/core_driver directory for details
of how to use this.

There is also a porting guide in the doc/porting and test reports in the
doc/test_reports directory.
