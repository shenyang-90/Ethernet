v 1.1.7
gem_gxl_drv_1_1_7.tar.gz

RSC Offload Linux update

New -   Linux driver RSC (or LRO) offload support. Includes multi-buffer Rx
        handling, previously avoided by declaring large ring buffers.
        Also interrupt moderation and rx flow filtering, controlled by ethtool
        commands.

        error while queueing frame for Tx.
Fix -   Linux driver now unmaps & frees Tx buffers in case of error when
        preparing to transmit.


06 July 2015
v 1.1.6
gem_gxl_drv_1_1_6.tar.gz

Linux 64-bit DMA update

New -   Support for 64-bit Linux compilation, allowing 64-bit DMA addressing.
        Note - Linux driver initialises AXI with ar2rMaxPipeline depth limited
        to 2, to avoid tx problem found in NIC FPGA testing. This was detected
        in NIC PCI configuration when compiling for 64-bit use, and may not
        affect other environments.
New -   Improved debug logging including register dump & Tx descriptors log
        (queue 0 only)
Fix -   Rx buffer DMA mapping size corrected (unlikely to have caused errors).
Fix -   Possible initAllRegs bug fixed, which may have caused unexpected
        interrupts at driver initialisation.


24 Mar 2015
v 1.1.5
gem_gxl_drv_1_1_5.tar.gz

Core driver update

Fix -   Rx descriptor buffering can cause a problem when buffering FIFO
        (calculated from `define gem_axi_rx_descr_rd_buff_bits in the _defs.v
        file) is defined larger than the Rx ring. The DMA buffering may try
        to read descriptors from outside the defined ring in this case.
        To prevent this, an extra "end-stop" descriptor was added to the
        Rx ring.  This is handled entirely within the core driver and does
        not affect the driver API usage.
Fix -   Minor adjustment in max Tx frame size calculation API: now reduced by
        10% to give more safety margin.
