customer_demo_sys_bus_memory_adapter

Adapter to/from AXI slave memory model and AXI VIP TLM port.  The reason this is done as an adapter is to that customers can swap the system bus VIP to their own bus protocol UVC and bridge.  Note that because inheritance is used the functions that implement read_mem, write_mem and the other write_* analysis port implementations should NOT use/call super!
