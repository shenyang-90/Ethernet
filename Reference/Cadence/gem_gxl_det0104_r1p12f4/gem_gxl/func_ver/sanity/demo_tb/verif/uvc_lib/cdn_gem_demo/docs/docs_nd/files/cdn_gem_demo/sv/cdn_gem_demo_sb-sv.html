cdn_gem_demo_sb

This is the cdn_gem_demo UVC scoreboard class.  This scoreboard operates on a single queue, for multi-queue operations multiple scoreboards have to be instanced and configured.

calc_pad_length

virtual function int calc_pad_length( int  data_length )

Calculate the number of zero that would be padded at the end of an AXI write transaction if the number of byte in the injected Ethernet transaction is not integer multiple of that in the AXI burst.  This is done in order to enable scoreboard comparison without taking out the zeroes padded at the end of the AXI write transaction at host side.

Parameters

data_lengthThe data length of the Ethernet transaction.
