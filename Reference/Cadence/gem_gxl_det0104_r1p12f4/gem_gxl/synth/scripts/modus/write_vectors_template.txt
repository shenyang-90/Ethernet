#Padding template file to define timing relations between various signals during shift and capture cycle.
#The parameters will be used by write_vectors command of Modus. The supported arguments are given below.
#This file can also facilitate the simulation debug.
#Copy this file to a new location and specify accordingly. It is recommended to have separate files for
#parallel and serial simulations, though not mandatory.
#If nothing specified, the flow will assume the defaults value from RDF.

#Example 1: parallel simulations with scan to define padding relations between test signals
#Beginning of the example 1

-explicitshifts 2
-scanbidioffset 2
-scanperiod 10
-scanpioffset=0
-scanpioffsetlist=cdb_pclk=4,cmn_psmclk_in=4,cmn_scanclk_fullrt=4
-scanpulsewidth 2
-scanstrobeoffset 3
-scantimeunits ns
-testbidioffset 0
-testperiod 20
-testpioffset 0
-testpioffsetlist 
-testpulsewidth 1
-teststrobeoffset 19
-testtimeunits ns
-waitcycleafterdynamic 2
-waitcyclebeforepulse 1
-waitcyclebeforescan 2
-waitcyclebeforescanprecond 1
-waitcyclebeforescanexit 1

#End of the example 1


#Example 2: Simulation debug example
#Beginning of the example 2

-testrange=2.1.1.2.1.5
#This will force write vectors to generate only the testbench containing the timing window for the given pattern

-testrange=1.2.1.2.1:1.2.1.3.15
#This will cause write vectors to generate only the testbench with the odometer range above

#End of the example 2
